# Glacé IJssalon

A polished static landing page for a fictional artisanal ice cream salon, Glacé. The project presents the brand identity, signature flavors, production philosophy, and contact details in a modern single-page format.

## Overview

This repository contains a responsive marketing homepage designed for a premium ice cream concept. The page is built with plain HTML and CSS, with no framework or build step required.

The site emphasizes:

- artisanal craftsmanship
- precise recipe formulation
- premium ingredients
- a modern, warm luxury aesthetic
- Dutch-language brand messaging for a local market

## Project structure

- `glace-ijssalon.html` — the complete landing page and styling
- `glace-ijssalon-data.csv` — sample flavor/product data used to describe the menu
- `Russian_Ice_Cream_Routine.xlsx` — additional supporting data or reference material

## Features

- responsive one-page layout
- fixed navigation and mobile menu
- hero section with premium branding
- flavor cards for signature products
- manufacturing/process information
- contact and CTA section
- custom styling with a warm cream-and-red palette

## How to view the site

Because this is a static HTML page, you can open it directly in a browser:

1. Clone or download this repository.
2. Open `glace-ijssalon.html` in your browser.

Optional local server:

```bash
cd glace-ijssalon
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000/glace-ijssalon.html
```

## Notes

- The project is intentionally lightweight and easy to customize.
- Styling and content are embedded directly in the HTML file.
- The flavor data in `glace-ijssalon-data.csv` can be adapted for future expansion or integration with a backend.
